# Medical Graphical Abstract Designer

Design a single figure from which a reader can reconstruct the paper's main comparison or organizing idea and understand its conclusion. Match the author's language for discussion and the requested publication language for labels. Work on a new version. Keep the supplied manuscript, previous artwork and unrelated open Illustrator documents intact.

## 1. Check the environment

Use [Illustrator setup and drawing](references/illustrator.md) for the first connection, a changed environment or a failed check. Reuse an existing server when possible. Create a disposable document, draw editable objects through MCP, save and reopen the AI, and actually view an export. Record the versions and operations verified. On subsequent manuscripts check that the same connection responds and targets the intended application.

If this environment cannot draw, continue manuscript review, reference review and design work locally. Report the failed operation and its consequence. Switching to native Illustrator scripts requires the user's explicit consent. A user who asks only for analysis or a plan can stop before illustration.

## 2. Read the manuscript in full

Identify the authoritative manuscript version and its supporting tables, figures and supplement. Ask immediately if the available versions conflict on a material fact. Capture each method and finding in the **fact sheet** in [Design records](references/design-records.md). Use separate tags for article type, study design, data source and evidence structure. Allow several tags per paper. Track sequential, parallel and validation relationships and identify which sample supplied each analysis. Distinguish directly supported findings, interpretation, hypotheses and future work. Resolve a missing group, denominator or estimate from the source or ask the author before drawing that claim.

## 3. Study published graphical abstracts

Find high-quality work matched to the topic, design and evidence structure. Search through available scholarly tools such as SciSpace or PubMed using public topic and design terms. Open the publisher page or open full text, then view the figure itself. If a journal is named, inspect recent examples from that journal and check its current author instructions on dimensions, format and AI-assisted artwork. Record the source and date. If its policy precludes the proposed production route, explain it before drawing for that submission.

Use the **seven-field reference card** for each example. A study can be the closest scientific match while another offers the clearest layout. Explain their different roles. If a picture is inaccessible, try an alternative primary source. Label a general illustration or a main-text figure accurately. If suitable images still cannot be viewed, explain what is missing and ask for an accessible example or agreement to plan with limited references. Derive claims and values from the manuscript. Redraw original artwork.

## 4. Propose the design and await the author's decision

Read [Layout choices](references/layout-choices.md), recommend one primary layout and explain why it fits the paper. Use the **author proposal** and **omission table** in the design records. Present three distinct parts in plain language.

1. **Content and structure.** Give one take-home sentence, a visible wireframe with simple shapes and connectors, the reading order, what each module shows, and the meaning of each key connection.
2. **Visual form.** Name the chosen form, what the reader can compare or follow, why this layout suits the evidence, and what the visual emphasis communicates.
3. **Omissions.** Give the author a separate, manuscript-specific table of retained, merged, captioned and omitted material. Explain the effect of each decision on interpretation.

Ask the author to approve all three parts or specify changes. Wait for their response before creating polished artwork. Record approval against the proposal version. Submit a material change to the central claim, structure, evidence relationships or significant omissions for renewed approval. Correct minor alignment, typography and spelling during review.

## 5. Draw, inspect and deliver

Build the approved figure through Illustrator MCP. Draw the actual research actions and comparisons, place branch-specific results next to the evidence that supports them, and leave enough space for the central finding. Create named layers, editable paths, groups and live text. Use [Illustrator setup and drawing](references/illustrator.md) for the execution route and [Delivery checks](references/delivery-checks.md) for review.

Export, **view the actual files**, log specific defects, repair the editable master, export again and recheck. Deliver a layered AI master, a PNG preview, a vector PDF and a short check report by default. Supply the files the target journal requests when one is specified. State which route ran, which checks passed, what still needs the author's judgment and whether a journal-specific requirements check was possible.
